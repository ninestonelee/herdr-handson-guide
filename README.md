# Herdr 핸즈온 가이드 · 터미널이 처음인 사람을 위한

**바로 보기:** https://ninestonelee.github.io/herdr-handson-guide/

AI 코딩 에이전트(Claude Code, Codex 등)를 한 화면에서 여러 개 다루는 터미널 도구 [Herdr](https://herdr.dev)를 처음 쓰는 분을 위한 단계별 웹 가이드입니다. 기준은 Herdr TUI 0.9.5(2026-11-20)이고, 진행 상황은 내 브라우저에만 저장됩니다.

- **실제 화면**: 연습용 세션에서 직접 실행해 찍은 화면입니다. 개인 폴더 경로는 가렸습니다.
- **영상 화면**: 참고한 유튜브 영상의 일부 장면을 채널·영상 제목·시각과 함께 인용했습니다. 유튜버의 얼굴이나 캐릭터가 보이는 장면은 그림 대신 원본 영상의 해당 장면 링크로 바꿨습니다. 참고 영상 전체 목록은 가이드의 부록 E에 있습니다.
- **공식 화면·문서**: https://herdr.dev

이 가이드는 비공식 학습 자료이며 Herdr 개발팀과 관련이 없습니다. 명령이 맞지 않으면 `herdr --help`와 공식 문서를 기준으로 확인해 주세요.
